# Daily candidate review

Run at the first Context Grove access on each UTC date, before task work. Read `.context-grove/REVIEW_LOG.md`; if a completed row exists for today's UTC date, reuse its report and stop. Otherwise follow `.context-grove/DAILY_REVIEW.md` exactly. Review all pending candidates, write an additive dated report and log entry, and coordinate through the lock or Git merge rules. Do not promote knowledge without explicit maintainer approval.

---

# Revisão diária dos candidatos

Execute no primeiro acesso ao Context Grove em cada data UTC, antes de iniciar a tarefa. Leia `.context-grove/REVIEW_LOG.md`; se houver uma linha concluída para a data UTC de hoje, reutilize o relatório e encerre a revisão. Caso contrário, siga exatamente `.context-grove/DAILY_REVIEW.md`. Revise todos os candidatos pendentes, escreva um relatório datado aditivo e atualize o log, coordenando pelo lock ou pelas regras de merge Git. Não promova conhecimento sem aprovação explícita de um mantenedor.
