# Knowledge consultation protocol

Before changing code, configuration, infrastructure, or project policy:

1. Read the repository's agent entrypoint instructions and check the working tree for existing user changes.
2. Check `.context-grove/CATALOG.md` and read the consultation, security, and contribution rules relevant to the task.
3. Read relevant canonical docs and decisions. Use the MCP catalog/search/read tools when available; verify important guidance against its cited source and freshness.
4. Inspect the current implementation and nearby tests or examples. Knowledge informs the work; it does not replace source inspection.
5. If sources conflict or are stale, record the conflict in the task handoff and seek maintainer guidance before relying on it.
6. At the first access on a new UTC date, complete [DAILY_REVIEW.md](DAILY_REVIEW.md) before task execution.
7. During and after work, capture reusable discoveries under [LEARNING.md](LEARNING.md) when warranted.

For read-only questions, consult the relevant source before answering and cite it in the response.
